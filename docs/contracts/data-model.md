# Contratto del modello dati

Stato: scheletro M0, non congelato.

Il modello canonico verrà generato e riconciliato a partire da modello visibile, istruzioni, guida di calcolo, XSD e overlay. Ogni campo dovrà registrare identificativo stabile, label, quadro, percorso XSD, tipo, cardinalità, regole, periodo di efficacia, provenienza e livello di supporto.

`TG-COMPLIANCE` blocca il congelamento del dominio. Nessun componente UI può introdurre costanti fiscali o mapping non presenti nel catalogo.
